# Python Time Dilation Calculator

## Overview

This project is a Python-based calculator exploring time dilation, a phenomenon predicted by Einstein's theory of special relativity.

The calculator examines how the passage of time differs between reference frames when relative motion occurs at speeds approaching the speed of light.

## Concepts

- Special relativity
- Time dilation
- Lorentz factor
- Relative velocity and the speed of light

## Purpose

I developed this project to explore the mathematical relationship between relative motion and the passage of time, translating a concept from theoretical physics into a practical computational tool.

## Language

Python

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Run `time_dilation_calculator.py` using Python.

## Note

The calculator uses the equations of special relativity. Its supported inputs and outputs depend on the implementation in the Python source file.
